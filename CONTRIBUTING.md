# Contributing

Read [setup](README.md) and [architecture](docs/architecture.md). Keep changes focused and preserve original coursework and third-party notices.

## Checks

```sh
python3 scripts/check-site.py
python3 scripts/check-docs.py
```

Explain behavior changes and checks actually run in pull requests. Do not commit credentials, local environments or generated build caches. Report vulnerabilities privately through GitHub security reporting. Historical lab submissions should remain distinguishable from maintenance updates.
